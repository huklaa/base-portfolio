## One-line pitch
Base Portfolio turns a public Base wallet address into an explainable, read-only view of assets, app relationships, payment behavior and verifiable onchain activity.

## Problem
Wallet explorers show transactions; many dashboards show balances. Neither consistently explains which applications a wallet actually uses, how activity changes, and which onchain claims can be independently checked.

## Solution
Paste any public Base address to inspect portfolio exposure, recent activity, wallet behavior, app relationships, stablecoin flows, strict builder attribution evidence and smart-account signals. The new tokenized-stock module is under review, not yet a live feature.

## What is working today
- Public read-only Base mainnet address analysis
- ETH and ERC-20 holdings, token allocation and recent transactions
- Economic fingerprint and transparent behavioral heuristics
- Stablecoin/payment analysis, activity changes and app relationships
- ERC-8021 and ERC-4337 evidence modules
- Shareable address links and public profile exports

## What is not yet verified
- No independently confirmed user/retention metrics; do not invent them.
- Tokenized stocks are an unmerged draft PR; do not claim live status.
- Protocol-specific DeFi collateral and borrowing positions are not implemented.
- Revenue is not active. Potential B2B API / professional analytics are hypotheses.

## Business model hypothesis
Keep the public wallet viewer free. Offer paid, rate-limited developer API access for bulk wallet intelligence and optional enterprise exports/analytics, subject to user research and compliance review.
